# MIKROABENTEUER – App v0.1

Diese Version ist eine installierbare Progressive Web App (PWA).

## Enthalten
- Startseite im MIKROABENTEUER-Stil
- 3 Touren
- Kartenpunkte für Lippische Velmerstot, Olgahafen/Hude und Hessisch Oldendorf
- OpenStreetMap-Karte
- Tourdetails
- vorbereiteter GPX-Button
- PWA-Manifest und Service Worker

## Veröffentlichung
Die App kann z. B. über GitHub Pages veröffentlicht werden. Lege alle Dateien in ein öffentliches GitHub-Repository und aktiviere unter Settings → Pages die Veröffentlichung aus dem Branch `main` / Root.

Danach lässt sich die Web-App auf Android in Chrome über das Menü zum Startbildschirm hinzufügen.
